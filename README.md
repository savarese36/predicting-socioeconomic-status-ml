# Predicting Socioeconomic Status Using Machine Learning

## Overview
This project investigates how demographic and housing-related variables can be used to predict socioeconomic status (SES) across Georgia census tracts.

## Dataset
American Community Survey (ACS) 5-Year Estimates
2,796 Georgia Census Tracts

## Methods
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Random Forest
- Naïve Bayes
- K-Nearest Neighbors
- Multilayer Perceptron

## Key Findings
- MLP achieved the highest classification accuracy.
- Median home value was the strongest predictor of SES.
- Median rent was the second most important predictor.
- Housing characteristics were more predictive than most demographic variables.
